O pacote está disponível no repositório oficial do _python_, o PyPI, sob o nome [tjsp_unidades](https://pypi.org/project/tjsp_unidades/).

Para instalar basta dar o comando:

```shell
# Instala pacote
pip3 install tjsp_unidades

# Instala pacote com versão específicada
pip3 install tjsp_unidades=0.1.1

# Instala pacote mais atual
pip3 install tjsp_unidades --upgrade

# Uninstall
pip3 uninstall tjsp_unidades
```
